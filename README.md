# יועץ AI למיסוי יחיד ושכר (digitaltax2025-ui)

אפליקציית צ'אט + מחשבונים, המבוססת על Next.js ומודל Claude, המתמחה
במיסוי יחיד ושכר בישראל: מס הכנסה, ביטוח לאומי (בדגש מילואים ודמי לידה),
מע"מ, דיני עבודה, פיטורים/התפטרות, גמר חשבון, חופשה/מחלה/הבראה, ומעבר בין
שכיר לעצמאי.

## מבנה הפרויקט

```
docs/system-prompt.md        # "המוח" של הסוכן — פרומפט המערכת המלא (עברית)
lib/systemPrompt.ts          # טוען את פרומפט המערכת עבור ה-API
lib/taxRates.ts              # טבלת נתונים כספיים (מדרגות מס, ביטוח לאומי וכו') — יש לעדכן שנתית!
lib/calculators.ts           # לוגיקת החישובים (טהורה, ללא UI)
app/api/chat/route.ts        # נקודת קצה שמזרימה תשובות מ-Claude
app/page.tsx                 # עמוד הבית: צ'אט + פאנל מחשבונים
components/                  # רכיבי UI (צ'אט, מחשבונים)
```

## הפעלה מקומית

1. התקנת תלויות:
   ```bash
   npm install
   ```
2. הגדרת מפתח API:
   ```bash
   cp .env.example .env.local
   # ולערוך את .env.local ולהזין ANTHROPIC_API_KEY אמיתי
   ```
   ללא מפתח, המחשבונים (מחצית הימנית של העמוד) עדיין עובדים באופן מלא —
   רק הצ'אט ידרוש מפתח API כדי לענות בפועל, ויציג הודעת שגיאה ברורה אם
   הוא חסר.
3. הרצה:
   ```bash
   npm run dev
   ```
   ואז גלישה ל- http://localhost:3000

## עדכון נתונים כספיים (חשוב!)

הנתונים בקובץ `lib/taxRates.ts` (מדרגות מס, אחוזי ביטוח לאומי, שכר
מינימום, תעריפי הבראה, תקרות דמי לידה/מילואים) הם **ערכי דוגמה** ולא
מספרים מאומתים לשנה נוכחית. יש לעדכן אותם:

- בתחילת כל שנת מס (בד"כ ינואר) מול רשות המסים והמוסד לביטוח לאומי,
- ובכל פעם שמתפרסם שינוי חקיקה/תקנות מהותי.

פרטי הרקע המשפטי לכל נושא נמצאים ב-`docs/system-prompt.md`.

## פריסה (Deployment)

האפליקציה היא Next.js רגיל וניתן לפרוס אותה בכל שירות שתומך בו (למשל
Vercel). יש להגדיר את משתני הסביבה `ANTHROPIC_API_KEY` (חובה) ו-
`ANTHROPIC_MODEL` (אופציונלי) בהגדרות הפרויקט בשירות הפריסה.

## כתב ויתור

המידע והחישובים באפליקציה זו כלליים ומיועדים למטרות הכוונה והמחשה בלבד.
הם **אינם מהווים ייעוץ מס, ייעוץ משפטי, או ייעוץ פנסיוני פרטני**, ואינם
תחליף לפנייה לרואה חשבון, יועץ מס, עורך דין או המוסד לביטוח לאומי — בפרט
לפני נקיטת צעדים מול רשויות (הגשת דוחות, השגות, ערעורים, הצהרות הון,
תביעות לביטוח לאומי). יש לאמת כל נתון מספרי מול המקור הרשמי העדכני לפני
הסתמכות עליו.
